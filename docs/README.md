## Contributing

When adding new documentation:

1. Use descriptive, searchable filenames (e.g., `FEATURE_NAME_DOCS.md`)
2. Include a table of contents for longer documents
3. Add code examples and diagrams where helpful
4. Update this README with links to new documentation
5. Follow Markdown best practices for formatting

## Documentation Standards

- Use clear, concise language
- Include practical examples
- Document both "what" and "why"
- Add troubleshooting sections for complex features
- Reference source code files where appropriate
- Keep documentation up-to-date with code changes
